# [Hard] Pwn - P2P Operator Terminal

## Category
Pwn

## Difficulty
Hard

## Author
Acfirth

## Description
A 64-bit binary simulating a "P2P Operator Terminal" for "reporting incidents". It has 2 common vulnerabilities in the binary, however you have to find a way to bypass the protections in place. Also to even get to the stage where you can exploit the vulnerabilities, you need to reverse the obfuscated password which you can use to login.

## Objective
Reverse the binary, locate the vulnerabilities, find a way to exploit the vulnerabilities and find a way to get the flag.

## Provided Files
- The challenge binary
- Docker deployment files (not provided for the original CTF challenge)
