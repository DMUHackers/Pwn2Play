## Description

A massive archive of nested directories and files has been provided. Somewhere inside the chaos lies the flag.

Most files contain junk data, repeated messages or distractions, but one file contains something different.

Can you navigate the directory hell and recover the hidden flag?

## Objective

Search through the extracted directory structure, identify the anomalous file and recover the encoded flag.
