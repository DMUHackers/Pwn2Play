# [Easy] OSINT - Geolocation - Solve Guide

## Overview

This challenge provides an image of a house and asks for the name of the location.

The required answer format is:
```

```
## Initial Analysis

Begin by inspecting the provided image carefully.

Useful details to look for include:

- Building style
- Distinctive architectural features
- Nearby signs
- Road layout
- Visible landmarks
- Image metadata
- Any unique surrounding features

## Method

The image shows a distinctive historic property. By researching the visible features and comparing them with online images of similar locations, the site can be identified as Meriden Moat House.

Useful OSINT techniques include:

1. Reverse image searching the provided photo.
2. Searching for visible architectural features.
3. Checking local heritage and property records.
4. Comparing the provided image against known images of the suspected location.
5. Confirming that the visual features match the target image.
