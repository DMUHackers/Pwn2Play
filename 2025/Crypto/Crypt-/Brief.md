## Description

We have intercepted communications between suspicious parties, but the contents appear to be encoded using emojis.

A file named `flag.txt` has been recovered. It contains an emoji-based ciphertext, alongside a supporting `README.md` that provides context for the challenge.

Your task is to analyse the encoded message and recover the flag.

## Provided Files

- `flag.txt` - emoji-encoded ciphertext
- `README.md` - challenge context and hint material

## Objective

Decode the emoji ciphertext and recover the flag.

## Notes

The challenge description hints that the intercepted communications involve sending numbers. Use this to guide your analysis of the emoji encoding scheme.
