# [Easy] Misc - Beethoven's Message

## Category
Misc

## Difficulty
Easy

## Author
x41x41x41 | JohnOP

## Description
A fragment of a long-forgotten manuscript has surfaced — nothing but a scattered sequence of tones, hastily transcribed and never explained. It's said the composer intended it for a single recipient, someone who would understand what others could not.

## Objective
Identify the musical notes played in the provided audio file and assemble them into the hidden message.

## Provided Files
- `beethoven.mp3` (or similar audio file containing a sequence of piano notes)

## Flag Format
P2P{MESSAGE}

## Notes
- The flag consists only of letters representable as musical notes (A–G)
- Each note played corresponds directly to one character of the flag
- No musical theory knowledge is strictly required — note recognition tools are a valid approach
